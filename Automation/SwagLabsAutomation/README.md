# Swag Labs QA Project

## Project Overview

This project is a QA testing project for the **Swag Labs** demo application. The project includes manual testing activities and Selenium automation testing to validate key application functionalities.

## Testing Performed

* Test Case Creation
* Test Execution
* Functional Testing
* Regression Testing
* Defect Identification and Reporting
* Automation Test Execution

## Test Scenarios Covered

* Login Functionality
* Product Selection
* Add to Cart
* Cart Validation
* Checkout Process

* Selenium WebDriver
* TestNG

* GitHub
